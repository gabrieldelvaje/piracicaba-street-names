# Metodologia

## Fonte
CNEFE — Cadastro Nacional de Endereços para Fins Estatísticos, Censo Demográfico 2022 / IBGE.

Município: Piracicaba/SP — código 3538709.

## Unidade de análise

Foram usadas duas visões:

1. Denominação única:
   - tipo do logradouro
   - título
   - nome do logradouro

2. Denominação por localidade:
   - localidade
   - tipo do logradouro
   - título
   - nome do logradouro

A primeira é usada para contagens gerais. A segunda preserva o contexto territorial.

## Limitações

- repetição de sobrenome não comprova parentesco;
- título não representa o gênero de todos os homenageados;
- categorias temáticas são exploratórias;
- o CNEFE não informa a origem histórica de cada nome;
- podem existir variações de grafia e duplicidades cadastrais.
