# Piracicaba Street Names

Projeto de data story sobre os nomes das ruas de Piracicaba (SP).

## Conteúdo

- `carousel/` — 7 imagens finais do carrossel
- `data/insights_summary.csv` — principais números consolidados
- `docs/methodology.md` — metodologia
- `docs/insights.md` — principais achados
- `src/build_streets.py` — script para reproduzir o tratamento do CNEFE
- `requirements.txt` — dependências

## Fonte principal

IBGE — CNEFE, Censo Demográfico 2022  
Município: Piracicaba/SP — código IBGE 3538709

Arquivo oficial:
https://ftp.ibge.gov.br/Cadastro_Nacional_de_Enderecos_para_Fins_Estatisticos/Censo_Demografico_2022/Arquivos_CNEFE/CSV/Municipio/35_SP/3538709_PIRACICABA.zip

## Principais achados

- bairros apresentam padrões temáticos de nomenclatura;
- Nova Piracicaba concentra nomes de flores, plantas e aves;
- Mário Dedini reúne árvores e pedras/gemas;
- Cidade Jardim possui conjunto marcante de países;
- sobrenomes como Furlan, Trevisan, Ometto, Dedini e Pecorari aparecem repetidamente;
- títulos como Doutor, Professora, Professor, Coronel, Padre e outros também aparecem de forma recorrente.

## Observação

O CNEFE é uma base de endereços, não um cadastro histórico de homenagens. As categorias temáticas são exploratórias e afirmações históricas devem ser validadas em legislação e documentação municipal.
